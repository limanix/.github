# Limanix

Linux development environments on macOS, configured with TOML and NixOS modules.

Keep your project and editor on your Mac; run tools, services, and builds inside
a Linux VM. Limanix uses Lima for virtualization and NixOS to configure the guest.

- [Limanix](https://github.com/mr-chelyshkin/limanix) — the VM client.
- [Limanix modules](https://github.com/mr-chelyshkin/limanix-modules) — the standard NixOS module catalog.
- [Documentation](https://limanix.mr-chelyshkin.com/) — installation, configuration, and development guides.
