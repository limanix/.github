- Keep your project and editor on your Mac.
- Run tools, services, and builds inside a Linux VM.
- Describe your environment in TOML and select the NixOS modules your project needs.

## Try it

After installing the client and preparing `limanix.toml`:

```console
limanix create --config limanix.toml
limanix shell dev-box
```
